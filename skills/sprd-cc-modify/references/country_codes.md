## 特殊规则标识

| 标识 | 含义 |
|-----|-----|
| DFS-FCC | 使用 FCC 的 DFS 规则（美国体系） |
| DFS-ETSI | 使用 ETSI 的 DFS 规则（欧洲体系） |
| DFS-JP | 使用日本的 DFS 规则 |
| NO-OUTDOOR | 仅限室内使用 |
| DFS | 需要动态频率选择（雷达检测） |
| AUTO-BW | 允许自动带宽扩展 |
| NO-IR | 不能主动辐射（被动扫描） |

## 使用说明

当用户说"修改萨尔瓦多的5G频段"时，查表得 `SV`，然后在 `db.txt` 中查找 `country SV:` 块进行修改。

当用户说"所有DFS-FCC国家"时，需找出所有 `country XX: DFS-FCC` 的条目。
可在 db.txt 中执行：`grep "^country.*DFS-FCC" db.txt`
