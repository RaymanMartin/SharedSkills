## 模板约束

1. 章节名默认使用中文。
2. 不要省略“关键源码索引”。
3. 不要把“完整调用链”替换成简单函数列表。
4. 如果没有错误，就不要硬输出“层级错误订正”。
5. 必须有至少一张时序图。
6. 必须有至少两张分阶段流程图。
7. 状态机图只允许来源于真实代码 StateMachine。
